# Security and safety

## Reporting a problem with the prompts

If a prompt can lead an agent to do something unsafe (delete data without a backup, remove a protected package, leak personal data, skip an approval gate), please open an issue or contact the maintainer through https://www.geeklord.com/contact-us/ . Don't include personal data from your phone.

## If you think you are being watched

Stalkerware is often installed by someone close to the victim, and removing it can alert them and escalate the situation. Before you remove anything:

- Plan from a different device you trust.
- Contact a support service: the [Coalition Against Stalkerware](https://stopstalkerware.org), a local domestic-violence service, or for journalists and activists the [Access Now Digital Security Helpline](https://www.accessnow.org/help/).
- Preserve evidence first. The scan prompt can save it to a local folder.

This project is a screening tool, not a forensic service. A clean result does not prove a device is clean.
